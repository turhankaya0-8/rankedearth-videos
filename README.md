# Ranked Earth — Instagram queue

Daily 3D "Top 10" Reels for [@rankedearth.8](https://www.instagram.com/rankedearth.8/).

- `videos/` – Instagram-ready Reels (served to Instagram from this public repo)
- `queue.json` – posting order, captions and status (`queued` / `published` + permalink)
- `publish_next.py` – publishes the next queued Reel (run daily by a scheduled task)
- `PRIVACY.md`, `DATA-DELETION.md` – pages required by the Meta app

No access tokens are stored here.
